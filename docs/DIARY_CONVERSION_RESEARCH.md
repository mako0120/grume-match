# グルメ日誌｜大阪 — 案件獲得に向けたCRO改善ログ（2026-10-17）

## 目的・前提

サイトの目的は**大阪の飲食店から、グルメ日誌本人への適法なInstagram PR相談を受ける**こと。Instagramの公開済み投稿以外の制作データ、共有デザイン、Canvaテンプレートや内部資料は表示しない。写真フィードPR基本料金は**Instagram投稿1件8,000円（税込）**。画像枚数では課金しない。動画込みPRは15,000円（税込）から。追加媒体、使用権、交通費、修正、訪問時間は契約前に合意する。費用・投稿内容・日程の合意がない相談から契約を発生させない。

### 参照した外部調査（独自成果を保証する根拠ではない）

- Baymard Institute, [Checkout UX 2025](https://baymard.com/research-articles/current-state-of-checkout-ux): 必須と任意をそれぞれ明示。不要な任意項目を意識させず、必要に応じて表示する。※元調査はECチェックアウトであり、PR相談フォームへの適用は仮説。
- Baymard Institute, [Minimize Form Fields](https://baymard.com/research-articles/checkout-flow-average-form-fields): 「段階数」だけより入力時に考える項目の数が重要、という洞察。今回、初回相談の必須項目を店舗名・担当者・メール・相談内容＋二つの同意とTurnstileにし、詳細を折りたたんだ。
- Unbounce, [Conversion Benchmark Report — Professional Services](https://unbounce.com/conversion-benchmark-report/professional-services-conversion-rate/): 対象データでモバイル流入が多く、短く平易なコピーに利点がある。数値ベンチマークを**グルメ日誌の実測CVRとは混同しない**。
- Google web.dev, [Core Web Vitals](https://web.dev/articles/vitals): LCP 2.5秒以内・INP 200ms以下・CLS 0.1以下を実ユーザー75パーセンタイルで検証する。ここでは高速化の**設計**をしたのみで実環境の実測完了ではない。
- 消費者庁, [ステルスマーケティングQ&A](https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing): PR/広告であることが明瞭な表記を徹底。高評価の指定、食べログ/Googleの対価付きレビューは受けない。

## 実装した変更

1. **Above-the-foldで商品明示**：飲食店向けInstagram PR / 本人が来店・撮影・編集・投稿 / 1投稿税込料金 / 無料相談を最初に示す。感情訴求だけに頼らない。
2. **利用シーン別導線**：「新メニューを知らせたい」「新規顧客向けに店を紹介」「こだわりを伝えたい」をクリックすると、固定の `goal` クエリパラメータによって相談フォームのヒントが変わる。自由記入欄は自動記入しない。トラッキングや個人情報のURL送信なし。
3. **初回の相談フォームを簡略化**：メール・店名・担当名・相談内容を必須に。予算とサービスは本人が「まず相談」と選ぶ場合にサーバーへ「相談」「未定」を送る。撮影詳細・電話・Instagram URLなどは任意の詳細欄。プラン申込みでは撮影・訴求情報を必須にし、商談内容を曖昧にしない。
4. **安心情報の明示**：相談無料／見積もり無料／送信時点では契約不成立／公開後7日以内の後払い／PR表記。偽の限定枠・偽口コミ・架空の導入企業ロゴ・売上保証・カウントダウンは使わない。
5. **Instagramで検証できる実績**：実際の公開済み投稿へのリンクのみ。埋め込みはクリック後に読み込み、初期ページの外部リクエストを抑える。過去30日のインサイトは必ず**計測日付きの過去実績**として掲載する。
6. **最小限の構成**：独立した外部JS解析ツールを追加せず、ネイティブのdetails/summaryで必要時のみ詳細を表示。サーバー側の料金・同意・RLSチェックは維持。

## 次の改善は実測ベースで検証

仮説を順に検証し、特定のCVR改善率は保証しない。

| 仮説 | 比較 | 主要指標 | 守るルール |
| --- | --- | --- | --- |
| 相談簡略化は送信完了を増やす | 旧フォーム vs. 新フォーム | 相談送信完了 / 相談画面訪問 | 必須同意・セキュリティを省略しない |
| 課題別コピーで適格な相談が増える | 汎用CTA vs. 利用シーン別CTA | 承認済み相談 / 全相談 | クリック率だけを目的にしない |
| 信頼訴求で有効な案件が増える | Instagram実績への導線順番 | 審査承認率、確定案件数 | 実在しない案件成果を使わない |
| モバイル操作性で完了率が上がる | 画面サイズ別のフォーム | デバイス別フォーム完了率 | 同意ベースの測定のみ |

**同意を得た集計方法とプライバシーポリシー整備前に追跡スクリプトやCookieは設置しない**。公開後、アクセス件数と相談件数の集計が可能になってから小さな実験を行う。

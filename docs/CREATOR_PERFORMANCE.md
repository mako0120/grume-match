# PROOF — Creator performance and media kit

フォロワー数ではなく「直近30日に実際どれだけ見られたか」で選ばれるようにする機能。
Creatorがインサイトの数字を貼り付けると、30日サマリーが自動で作られ、次の場所で使われる。

| 場所 | 誰が見る | 内容 |
|---|---|---|
| `/creator/performance` | Creator本人 | スクショ送信・PR窓口（一律料金）・Gmail営業 |
| `/order/<slug>` | 店舗（未登録でも閲覧可） | 一律料金プランの依頼ページ。候補日時を選んで依頼 |
| 応募者を選ぶ画面 | 店舗 | 応募者ごとの「30日 ◯閲覧・中央値・反応率・確認済」 |
| 指名オファーのCreator選択 | 店舗 | 同上。中央値の大きい順に並ぶ |
| `/restaurant/creators/[id]` | 店舗 | フルのメディアキット＋「この人に指名オファー」 |
| `/k/<slug>` | 誰でも（公開ONの時のみ） | 店舗営業用メディアキット＋店舗登録CTA |
| `/admin/performance` | 運営 | スクショを見て数字を登録 → 運営確認済み |

## Creatorがやること（3つだけ）

`/creator/performance`（実績とPR窓口）で：

1. **スクショを送る** — インサイト → コンテンツ → 30日間 → 閲覧数順の画面を撮って送るだけ。数字の入力は不要。
2. **PR窓口を公開する** — スイッチ1つ。一律料金（グルメ日誌は¥8,000・税込・Instagramリール1本・食事1名分は店舗負担）で依頼を受け付けるページ `/order/<slug>` が公開される。URLは既定でInstagramのアカウント名から作られる。
3. **Gmailで営業する** — 店名（任意で担当者名・メール）を入れて「Gmailで作成する」。Gmailの作成画面が、実績と「ご依頼はこちらから」のリンク入りの文面で開く。送信は自分のGmailから。送った店舗は記録される。

店舗は `/order/<slug>` で候補日時（1〜3つ）と任意のメモを入れて依頼する。料金・投稿内容・食事はプランで固定され、フォームからは変えられない（DB側で強制）。未登録の店舗は登録・ログイン後に同じページへ戻る。

## スクショの読み取り（APIなし・Claudeが随時判断）

外部のOCRやAI APIは使わない。送られたスクショは「読み取り待ち」になり、次のどちらかで登録する：

- **Claudeに頼む**：「実績スクショを読み取って」。Claudeは `.claude/skills/read-insights/SKILL.md` の手順で
  `npm run insights -- list` → 画像を見て書き起こし → `submit`（プレビューで照合）→ `--yes` で登録する。
  読めない場合は理由付きで差し戻す。必要な環境変数は `NEXT_PUBLIC_SUPABASE_URL` と `SUPABASE_SECRET_KEY`。
  定期的に処理したい場合は、Claude Codeのスケジュール実行（Routine）でこの依頼を毎日実行できる。
- **運営が画面で入力**：`/admin/performance` でスクショを見ながら同じ形式で入力して登録。

どちらも登録した数字は「運営確認済み」になり、Creatorに通知される。

## 入力形式（Claude・運営・手入力共通）

インサイト → コンテンツ → 30日間 → 閲覧数順 の画面を見ながら、1投稿1行：

```
エリア / 見出し / 閲覧数 / いいね / コメント / リポスト / シェア / 投稿時期
```

- 「2.7万」「1,106」「3週間」「4日」はそのまま入力できる（万表示は「約」付きの概数として扱う）
- 見出しは省略可。行のどこかに `https://` の投稿URLを入れるとリンクになる
- 区切りは ` / `・タブ・`|`（使わない場合は空白）。カンマは桁区切りとして読む
- 同じSNS・同じ計測日を再保存すると置き換え。月1回更新する（35日を過ぎると「更新待ち」表示）

## グルメ日誌の初期データ（Instagram・30日間・閲覧数順）

通常はスクショを送るだけでよい。手入力する場合は `/creator/performance` の「自分で数字を入力する」に、読み取り担当は `submit` のファイルにそのまま使える。計測日はスクリーンショットを撮った日にする。

```

小野原 / 漁港直営の新鮮な海鮮定食を堪能 / 2.7万 / 666 / 10 / 6 / 13 / 4日
天王寺 / 開店から行列 人気の一杯 / 2.5万 / 775 / 4 / 7 / 18 / 2週間
難波 / 大和肉鶏・近江鴨 お造り七種盛り / 1.4万 / 602 / 0 / 8 / 17 / 2週間
南淡路 / とにかくボリューム満点 / 1.0万 / 809 / 4 / 6 / 9 / 3週間
松原 / 泡系豚骨 一度は食べたい / 9,786 / 728 / 1 / 4 / 2 / 3週間
本町 / 職人が握る本格鮨を気軽に / 5,975 / 634 / 3 / 4 / 0 / 2週間
北新地 / 旬を揃える天麩羅コース / 5,446 / 618 / 2 / 11 / 0 / 2週間
```

自動で作られるサマリー（`tests/creator-performance.test.mjs` で固定）：

- 直近30日の8投稿で合計約12.4万閲覧（平均1.6万・中央値1.2万・最高2.7万）
- 全投稿が5,000閲覧以上
- 8本中5本が1万閲覧超え
- 最高約2.7万閲覧（淡路市・小野原）
- 8エリアで実績（大阪市内・北摂・南河内・淡路島）
- いいね合計5,938／反応率4.9%（いいね＋コメント＋リポスト＋シェア÷閲覧）

運営確認を付けるには、同じ画面のスクリーンショットを「運営確認」から送る。

## 店舗への営業での使い方

「営業」欄からGmailで送るのが基本。Instagram DMで送る場合は依頼ページのURL（`/order/<slug>`）を貼る。リンクプレビューに「グルメ日誌に一律¥8,000でPRを依頼」と実績の見出しが出る。

Gmailの文面（自動作成・`tests/pr-desk.test.mjs` で固定）：

> 件名：【グルメ日誌】◯◯様 PRのご提案（一律¥8,000・税込）
>
> はじめまして。大阪を中心にグルメ情報を発信している「グルメ日誌」です。…
> 直近の実績（運営確認済み）：直近30日の8投稿で合計約12.4万閲覧／全投稿が5,000閲覧以上／…
> ■ プラン　一律¥8,000（税込）でInstagramリール1本を投稿／お食事は1名分のみご提供ください／追加料金や価格交渉はありません
> ■ ご依頼はこちらから　https://<domain>/order/<slug>

## プライバシーと信頼性

- 数値は自己申告。運営がスクリーンショットと照合したものだけ「運営確認済み」。編集すると確認は外れる
- スクリーンショットはCreator本人と運営だけが見られる（オーディエンス情報が写ることがあるため店舗には出さない）
- 公開メディアキットは任意（初期は非公開）。メールアドレス・連絡先・スクリーンショットは表示しない
- 店舗が見られるのはログイン中の有効な店舗アカウントのみ（Creator同士・未ログインは不可）

# PROOF — Creator performance and media kit

フォロワー数ではなく「直近30日に実際どれだけ見られたか」で選ばれるようにする機能。
Creatorがインサイトの数字を貼り付けると、30日サマリーが自動で作られ、次の場所で使われる。

| 場所 | 誰が見る | 内容 |
|---|---|---|
| `/creator/performance` | Creator本人 | 入力・プレビュー・スクショ送信・メディアキット設定 |
| 応募者を選ぶ画面 | 店舗 | 応募者ごとの「30日 ◯閲覧・中央値・反応率・確認済」 |
| 指名オファーのCreator選択 | 店舗 | 同上。中央値の大きい順に並ぶ |
| `/restaurant/creators/[id]` | 店舗 | フルのメディアキット＋「この人に指名オファー」 |
| `/k/<slug>` | 誰でも（公開ONの時のみ） | 店舗営業用メディアキット＋店舗登録CTA |
| `/admin/performance` | 運営 | スクショと数字の照合 → 運営確認済み |

## 入力形式

インサイト → コンテンツ → 30日間 → 閲覧数順 の画面を見ながら、1投稿1行：

```
エリア / 見出し / 閲覧数 / いいね / コメント / リポスト / シェア / 投稿時期
```

- 「2.7万」「1,106」「3週間」「4日」はそのまま入力できる（万表示は「約」付きの概数として扱う）
- 見出しは省略可。行のどこかに `https://` の投稿URLを入れるとリンクになる
- 区切りは ` / `・タブ・`|`（使わない場合は空白）。カンマは桁区切りとして読む
- 同じSNS・同じ計測日を再保存すると置き換え。月1回更新する（35日を過ぎると「更新待ち」表示）

## グルメ日誌の初期データ（Instagram・30日間・閲覧数順）

`/creator/performance` にそのまま貼り付けられる。計測日はスクリーンショットを撮った日にする。

```

小野原 / 漁港直営の新鮮な海鮮定食を堪能 / 2.7万 / 666 / 10 / 6 / 13 / 4日
天王寺 / 開店から行列 人気の一杯 / 2.5万 / 775 / 4 / 7 / 18 / 2週間
難波 / 大和肉鶏・近江鴨 お造り七種盛り / 1.4万 / 602 / 0 / 8 / 17 / 2週間
南淡路 / とにかくボリューム満点 / 1.0万 / 809 / 4 / 6 / 9 / 3週間
松原 / 泡系豚骨 一度は食べたい / 9,786 / 728 / 1 / 4 / 2 / 3週間
本町 / 職人が握る本格鮨を気軽に / 5,975 / 634 / 3 / 4 / 0 / 2週間
北新地 / 旬を揃える天麩羅コース / 5,446 / 618 / 2 / 11 / 0 / 2週間
```

自動で作られるサマリー（`tests/creator-performance.test.mjs` で固定）：

- 直近30日の8投稿で合計約12.4万閲覧（平均1.6万・中央値1.2万・最高2.7万）
- 全投稿が5,000閲覧以上
- 8本中5本が1万閲覧超え
- 最高約2.7万閲覧（淡路市・小野原）
- 8エリアで実績（大阪市内・北摂・南河内・淡路島）
- いいね合計5,938／反応率4.9%（いいね＋コメント＋リポスト＋シェア÷閲覧）

運営確認を付けるには、同じ画面のスクリーンショットを「運営確認」から送る。

## 店舗への営業での使い方

1. `/creator/performance` でメディアキットのURL（例 `gourmet-diary`）を決めて公開ONにする
2. 営業DM・メールにURLを貼る。リンクプレビューに「合計約12.4万閲覧」などの見出しが出る
3. 店舗はページ下の「店舗として登録して依頼する」から登録し、指名オファーを送る

DM例：

> はじめまして、大阪でグルメ発信をしている「グルメ日誌」です。
> 直近30日で8投稿・合計約12.4万閲覧、全投稿5,000閲覧以上の実績があります（運営確認済み）。
> 実績まとめ：https://<domain>/k/gourmet-diary
> 有償PRでのご紹介をご検討いただけましたら、上のページから条件付きでご依頼いただけます。日程はタップで調整でき、DMでのやり取りは不要です。

## プライバシーと信頼性

- 数値は自己申告。運営がスクリーンショットと照合したものだけ「運営確認済み」。編集すると確認は外れる
- スクリーンショットはCreator本人と運営だけが見られる（オーディエンス情報が写ることがあるため店舗には出さない）
- 公開メディアキットは任意（初期は非公開）。メールアドレス・連絡先・スクリーンショットは表示しない
- 店舗が見られるのはログイン中の有効な店舗アカウントのみ（Creator同士・未ログインは不可）

## 2. 既存店へ送る提案（内容を各店舗ごとに調整）

> 以前はPRをご相談いただきありがとうございました。季節限定メニューや新商品の紹介を毎月計画的に行えるよう、「毎月フォトPR」（月29,800円・税込）と「毎月フォト＋リールPR」（月49,800円・税込）を新たに準備しています。どちらも原則月1回来店で制作し、実際の投稿データを簡易レポートとしてお伝えします。ご希望に応じて内容や開始月をお見積もりできます。新メニューのご予定があれば一度ご相談いただけますでしょうか。

必ず過去の関係・店の状況を確認して一対一で送る。存在しない再生数・集客成果・他店の実績は書かない。返信がなければ執拗に送らない。

## 3. 見積・契約時の確認欄

- 店舗・法人名、連絡担当者、対象の店舗・エリア（拠点ごとの料金）
- 写真プラン/写真＋リールプラン、税抜・税込価格、オプションと経費負担
- 制作月、来店候補日時、月1回の撮影枠、撮影時間の上限、料理提供・交通費
- 写真フィードやリール・ストーリーズの本数、投稿予定時期・媒体、PR表示
- テロップ/キャプションの誤記確認は1回、追加修正/再撮影は別途費用
- 動画尺・投稿するアカウント・素材納品/二次利用・広告配信許諾の有無
- 再生数/予約数/売上保証なし。実測可能な数値のみ共有
- 自動引落し・自動更新なし。次月以降は双方の同意が必要
- 請求条件は投稿公開後7日以内を基本とし、月末締め等を個別に明示合意
- 日程変更・キャンセル・延期・不可抗力・撮影に第三者が写った場合の対応
- 個人情報取扱、機密保持、制作物の保管/削除/権利帰属、トラブル時連絡先

**フォーム送信は契約成立ではない。** ネット上で有料の契約を直接確定させる場合は、特商法等の適用可能性と最終確認画面・重要事項表示を専門家確認。

## 4. 月次オペレーション（受注1店舗につき）

1. 受注前：単価、希望媒体、担当者、制作負荷、利益を見積。予算を下回る場合は内容変更を提案
2. 第1週：その月のPRテーマ・来店日時・訴求内容・投稿予定日を合意
3. 第2週：1回の撮影で必要な写真・動画を収録。実写のみ使用
4. 第3週：編集→事実確認（軽微1回）→適切なPR表示で投稿
5. 第4週：当該投稿の公開URL・取得できる実数だけを報告。請求書発行/入金確認を別管理
6. 次月：更新希望を確認、金額・内容・日程を再合意した場合だけ翌月分を確定

## 5. 経営指標の記録（実測が始まってから）

| 指標 | 算出方法 | 誤集計防止 |
| --- | --- | --- |
| 成約数 | 双方合意した新規契約数 | フォーム受付数を含めない |
| 正味継続月商（MRR） | 有効な契約の翌月に確定した継続料金の合計 | 見込み・解約済みを含めない |
| 利益/契約 | 税抜売上−実支出−本人労務費（内部評価） | 支払済みの外注費を二重計上しない |
| 取得単価（CAC） | 獲得に要した営業工数・経費 / 新規成約店舗数 | 分母が0件なら計算不能と表示 |
| 月次解約率 | 前月末に有効だった店舗のうち当月更新しなかった店舗の割合 | 期間の再合意/休止と区別 |
| 契約当たり労務時間 | 撮影＋移動＋企画＋編集＋確認＋報告＋請求 | 仕込み時の工数を見落とさない |
| 素材二次利用 | 明示許諾がある媒体・期間のみ | 無断の広告転用は禁止 |

### 週次の経営判断

- 当月の労務後貢献利益がマイナス：新規引受停止、見積と制作範囲を修正
- 撮影/編集時間が想定の120%超：修正回数・移動距離・納期の見直し
- 2ヶ月連続で再契約の意思確認が取れない：値引き連打ではなく理由のヒアリング
- 既存契約の利益を犠牲にしたSNS上の低単価キャンペーンは実施しない

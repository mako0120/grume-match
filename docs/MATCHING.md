# Matching

店舗とCreatorの相性を、説明できるルールで点数化する（AIは使わない）。
実装は `lib/matching.ts`（点数）と `lib/areas.ts`（エリア）。テストは `tests/matching.test.mjs`。

## 点数（0〜100）

| 要素 | 最大 | 内容 |
|---|---|---|
| エリア | 30 | 同じエリアで投稿実績 30 / 活動エリアが同じ 24 / 同じ地域（キタ・ミナミ・北摂など）で投稿実績 22 / 活動エリアが同じ地域 18 / 同じ府県 10 |
| 閲覧（30日・中央値） | 25＋5 | 2万以上25・1万以上20・5千以上14・2千以上8。運営確認済みなら＋5 |
| 反応率 | 10 | 6%以上10・4%以上7・2%以上4 |
| PR完了実績 | 20 | 5件以上20・3件以上15・1件以上10。無断キャンセル1件ごとに−15 |
| ジャンル | 10 | 案件ジャンル（焼肉など）が自己紹介・投稿見出しにある |
| FLASH | ＋15 | 「今行ける」がON |

- 70以上「とても合う」、50以上「合う」
- **除外**：案件の報酬がCreatorの最低報酬未満／無断キャンセル2件以上
- 理由（例「キタ（北新地）で投稿実績あり」「1投稿あたり中央値1.2万閲覧（確認済み）」）と注意（例「実績が35日以上前のもの」）を必ず表示する

## どこで使うか

| 場面 | 動き |
|---|---|
| 店舗が案件を公開 | 50点以上の上位10人に自動で「あなたの実績に合う新着PR案件」を通知（招待） |
| 応募者を選ぶ画面 | 応募者を相性順に並べ、理由・注意を表示 |
| 同画面「おすすめCreator」 | 未応募・未招待で15点以上の上位5人。「招待する」で通知 |
| 指名オファーのCreator選択 | 店舗のエリアとの相性順 |
| Creatorの案件一覧・FLASH | 招待あり → 相性順。カードに理由を表示 |
| 案件詳細（Creator） | 「あなたとの相性」「店舗から招待されています」 |

おすすめの基準（15点）は自動招待（50点）より低くしている。実績のない新しいCreatorでも、エリアと報酬が合えば店舗の目に入るようにするため。

## 招待のルール（DB: `invite_creators_to_campaign`）

- 公開中・募集中・締切前の公開案件だけ（指名オファーは対象外）
- 1回10人まで、1案件30人まで。同じCreatorへの招待・応募済みのCreatorへの招待はしない
- 招待は通知＋記録。Creatorの案件一覧に「招待あり」

## 実績の数（DB: `creator_track_records`）

PR完了数と無断キャンセル数だけを返す。他店舗の予約や支払いの内容は見えない。

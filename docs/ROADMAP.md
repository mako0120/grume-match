# Roadmap

## Phase 0 — Pilot operations

Goal: ソフトウェアを作りすぎる前に取引を成立させる。

- Creator 20名
- Restaurant 5店舗
- 有償案件 10件
- 手動運用で例外パターン収集
- グルメ日誌をCreator #1として実利用

Exit:
- 10件以上の完了案件
- 日程調整フローの主要例外が整理済み

## Expansion gate

大阪以外へ広げる条件:
- 店舗継続率
- Creator供給
- 地域ごとの案件fill rate
- 運営手動工数

を満たしてから京都・神戸等へ拡張。

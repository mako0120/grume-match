# グルメ日誌のInstagram DM相談導線

## 現状

- `/diary/request` のフォームは Supabase・Turnstile 設定が揃い、`DIARY_INQUIRIES_ENABLED=true` になるまで受付不可。
- 無効時は、店名を入力・送信させるフォームの代わりに **Instagram DM案内、3ステップ、コピー可能な相談文、公開プロフィールへのリンク**を表示する。
- `goal=new_menu|first_visit|story` と許可された `service` が指定されていれば、依頼目的に応じて相談文を変更する。`goal` と `service` はサーバーで許可リスト検証された情報のみ使い、自由入力をURLに含めない。
- 相談文の原本は `lib/diary/dm-template.ts` にあり、無効な引数・URLパラメータの文字列は文面に含めない。
- コピーはブラウザの Clipboard API をクリック時にだけ呼ぶ。非対応・拒否時には文字列を選択した状態にして、手動コピーを案内する。
- コピー操作で内容は**当サイトのサーバーに保存・送信されない**。Instagram上で手動送信し、Instagram側の個人情報取り扱いが適用される。
- DMの文章を生成しただけ・プロフィールを開いただけでは、送信・予約・成約・見積もり依頼完了を主張しない。DMの送信後も人間が内容を確認して商談・合意する。

## 商用運用

1. 依頼者が Instagram DM で送信した相談に、グルメ日誌運営者が直接返信する。
2. 案件管理はDM側で手作業。自動取り込み・外部CRM転送・自動返信はまだ行っていない。
3. 必ず適切なPR表記で制作し、レビューサイトへの対価付き口コミ、評価指定、虚偽記載を受託しない。
4. 一般のお客様の顔・声・個人情報は許可なく投稿しない。詳しくは `docs/DIARY_SHOOT_PRIVACY_CHECKLIST.md`。
5. 交通費や二次利用は必要に応じて見積もり時に確認する。通常フィード1投稿8,000円（税込）の価格単位は維持する。
6. テスト対象: 小画面のレイアウト、コピー成功・失敗、別タブで開く Instagram プロフィール、文面のプラン・目的反映、フォーム有効化時の正常切替。
7. 公開後は Netlify のデプロイステータスを確認する。GitHub CI 成功だけでは公開と判断しない。

## 未完了・承認が必要

- DMの件数・成約率は現在自動計測していない。効果向上の数値を捏造しない。
- 本番課金・メール通知・検索インデックス許可などは未実施。

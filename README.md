# GOURMET DIARY PR OS

飲食店とグルメクリエイターを、**有償PR案件・日程調整・納品・分析**まで一気通貫でつなぐプラットフォームです。

## Vision

- クリエイターの撮影・編集・投稿に、食事提供とは別の対価が返る
- 店舗はフォロワー数だけでなく、地域適合度・コンテンツ品質・実績から依頼相手を選べる
- DMで発生している日程調整・条件交渉・投稿確認をできるだけタップ操作と自動化に置き換える
- 将来的には「誰に、いくらで、何を依頼すると来店につながるか」を学習する飲食店PR OSへ発展させる

## Core products

- **MARKET** — 有償PR案件を探して応募
- **OFFER** — 店舗からクリエイターへ直接オファー
- **SCHEDULE** — 来店可能日時をタップして応募・確定
- **FLASH** — 今日・明日の空席とクリエイターを即時マッチング
- **STUDIO** — UGC写真・動画素材の納品と利用権管理
- **SIGNAL** — PR投稿の閲覧数（運営確認済み）・PRリンクの閲覧・来店・ROIの分析
- **REVIEW** — PR完了後の相互評価（双方が送るまで非公開）
- **DM → APP** — DMで来た依頼に返せるCreatorの依頼受付ページ（/c/…）と、店舗からの招待リンク（/i/…）
- **WALLET** — 報酬・請求・支払い管理
- **AUTOPILOT** — AIによる案件文生成、候補推薦、運用支援

## MVP principle

最初から全部を作らず、まずは個人運営でも回せる以下の流れを完成させます。

`Creator登録 → 店舗登録 → 案件作成 → 案件一覧 → 日程をタップして応募 → 採用/日時確定 → 来店 → 投稿URL提出 → 報酬管理`

詳細は `docs/PRD.md` を参照してください。運営（AI社員）の回し方は `docs/OPERATIONS.md`。有償公開の前にやることは `docs/COMMERCIAL_LAUNCH.md`。

## Compliance

有償PRの成果物は Instagram / TikTok / YouTube Shorts / UGC を中心とし、インセンティブと引き換えの口コミ投稿を標準成果物にはしません。
